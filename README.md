# Meu Blog | Estudos e Tecnologia

## Sobre o projeto

O Meu Blog é um site desenvolvido com HTML, CSS e JavaScript, com o objetivo de compartilhar conhecimentos, experiências acadêmicas e conteúdos relacionados ao mundo da tecnologia.

O projeto possui uma interface simples, organizada e responsiva, permitindo que o usuário gerencie suas próprias publicações.

## Funcionalidades

- **Adicionar publicações:** permite cadastrar novas publicações com título, categoria, descrição e imagem.
- **Editar publicações:** permite modificar as informações de uma publicação existente.
- **Excluir publicações:** permite remover publicações da página.
- **Pesquisar publicações:** permite localizar conteúdos pelo título, categoria ou descrição.
- **Armazenamento local:** utiliza LocalStorage para manter as publicações salvas no navegador.
- **Layout responsivo:** adapta o site para diferentes tamanhos de tela.

## Tecnologias utilizadas

- HTML5: estruturação do site.
- CSS3: estilização e organização visual.
- JavaScript: implementação das funcionalidades e interações.
- LocalStorage: armazenamento dos dados no navegador.

## Como executar o projeto

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.
4. Utilize o formulário para adicionar, editar ou excluir publicações.

Também é possível utilizar a extensão Live Server do VS Code para executar o projeto.

## Armazenamento de dados

O projeto utiliza o LocalStorage do navegador para armazenar as publicações.

Dessa forma, os dados continuam disponíveis mesmo depois que a página é atualizada ou o navegador é fechado.

Entretanto, as informações ficam armazenadas somente no navegador utilizado, não existindo integração com banco de dados.

## Objetivo acadêmico

Este projeto foi desenvolvido como atividade prática para aplicar conhecimentos de desenvolvimento web, trabalhando conceitos de estruturação HTML, estilização CSS, manipulação do DOM, eventos JavaScript e armazenamento local.
